음성으로 녹음한 일기를 AI가 분석해 감정·제목·요약·키워드를 자동 생성하는 일기 앱입니다. 16개 언어를 지원하며 기획·디자인·개발을 모두 직접 담당했고, 차별화된 기능과 완성도를 인정받아 Apple App Store “오늘의 앱”에 선정되었습니다.
진행 기간
2020.04 – 운영중
기술 스택
ReactReact NativeExpoTypeScriptFirebase

웹훅 1차 트리거 + 플랫폼 API 재조회의 이중 검증으로 결제·권한 불일치를 차단한 IAP 구독 동기화 구조

문제점
  • 웹훅만으로 결제 상태를 동기화하면 지연·유실·재전송에 의해 결제 결과와 앱 내 구독 권한이 어긋날 위험
  • iOS/Android 각 플랫폼의 웹훅 페이로드 형식·이벤트 종류가 달라 통합 처리 필요
  • 결제 직후 transactionId를 사용자와 매핑하는 명확한 식별 체계가 없으면 후속 웹훅과 사용자 연결 불가
해결 과정
  • 결제 직후 클라이언트가 받은 transactionId를 사용자 ID와 매핑해 저장, 이후 모든 웹훅 이벤트를 사용자와 정확히 연결
  • iOS/Android 각 플랫폼의 구독 웹훅을 Firebase Functions로 수신하되, 페이로드를 신뢰의 단일 근원으로 삼지 않고 1차 트리거로만 사용
  • 이벤트 수신 시 각 플랫폼 API(App Store Server API / Google Play Developer API)로 실제 구독 만료일·상태를 재조회해 최종 상태를 확정하는 이중 검증 흐름 구축
결과
  • 웹훅 지연·유실·재전송 등 외부 요인이 있어도 결제 상태와 앱 내 권한이 항상 일치하는 신뢰 구조 확보
  • iOS·Android 양 플랫폼에서 동일한 검증 흐름으로 동작, 신규 결제 이벤트 추가 시 동일 구조로 확장 가능
  • 운영 중 발생할 수 있는 결제 관련 CS·환불·미결제 권한 문제를 사전 차단

FlatList 기반 커스텀 캘린더를 오픈소스로 배포해 주간 3,000+ 다운로드 달성

문제점
  • 일기 앱의 핵심 진입점인 캘린더에서 본 앱의 디자인·인터랙션 요구를 충족하는 기존 RN 라이브러리가 부족
  • 직접 구현 시 다달이 부드러운 무한 스크롤과 렌더링 성능을 동시 만족시켜야 함
  • 본 앱에만 묻어두기엔 범용성이 있는 컴포넌트라, 다른 RN 개발자도 활용 가능한 형태로 정리·공개할 가치 판단
해결 과정
  • FlatList 기반으로 캘린더 뷰를 구현해 가상 스크롤로 무한 탐색이 자연스럽게 동작하도록 처리
  • 디자인 토큰·인터랙션 옵션을 외부에서 주입할 수 있도록 props 인터페이스를 추상화해 다양한 앱에 적용 가능한 독립 모듈로 분리
  • react-native-calendar-range-picker로 npm에 오픈소스 공개, GitHub 이슈·PR을 통한 외부 기여 흐름 구축
결과
  • 주간 3,000+ 다운로드 달성 (2026.04 기준), RN 생태계의 캘린더 컴포넌트 옵션 중 하나로 자리매김
  • 본 앱에서도 동일 모듈을 그대로 사용해 코드 중복 제거 및 유지보수 일원화
  • 외부 사용자 피드백을 통해 다양한 디자인·언어 요구를 흡수, 모듈 안정성 향상

오픈소스

fe-review-agents

N개의 관점을 독립 sub-agent로 분리해 추론 오염 없이 병렬 리뷰하는 Claude Code 플러그인

문제점
  • 단일 모델에 6개 관점(성능·코드 품질·버그·타입 안전성·접근성·보안)을 동시에 맡기면 추론 오염·mode collapse로 평가 품질 저하 우려
  • 병렬 설계하여 6개 리뷰어를 호출했으나 수만 토큰 diff로 모델이 호출을 분할 송신해 의도와 달리 직렬 실행되는 에러 현상 발생
해결 과정
  • 6개 리뷰어를 독립 sub-agent 컨텍스트로 분리해 자기 관점만 평가하도록 격리
  • 통합 에이전트가 6개 결과를 중요도순으로 종합하는 2단계 평가 구조 설계
  • diff를 임시 파일에 저장하고 각 리뷰어에는 파일 경로만 전달, 한 메시지에 6개 호출을 함께 담아 진정한 병렬 실행 보장
결과
  • 관점별 독립 컨텍스트로 추론 오염 없이 6개 차원의 PR 평가 제공
  • 단일 메시지 내 병렬 실행 확보로 전체 리뷰 소요 시간 단축
  • 통합 에이전트의 중요도순 종합으로 PR 작성자가 우선 대응 사항을 즉시 식별 가능
